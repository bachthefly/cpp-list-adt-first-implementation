# C++ List ADT Implementation

A C++ implementation of a **List Abstract Data Type (ADT)** developed as a data structures course project.

The project implements list operations using dynamic memory and a linked-list-based data structure.

## Implementation

- **C++**
- Dynamic memory management
- Linked list data structure
- List ADT operations

## Files

- `List.h` — List ADT interface and class definition
- `List.cpp` — List ADT implementation
- `main.cpp` — Driver program and testing
- `makefile` — Build configuration
- `ListADT.pdf` — Project specification

## Context

Developed as part of **CS 173: Intermediate Computer Science** at Denison University.
